# Web Dev-Eyes — Demos personales

Demos de Ourway y MyAccountant, desarrollos personales de Emilio Fonseca.

Se publican únicamente los frontends compilados con datos de ejemplo. Los repositorios fuente siguen privados. No se conectan cuentas, álbumes ni información financiera real.

Ourway conserva su escena orbital 3D y navegación. MyAccountant utiliza su conjunto de prueba propio y sus interfaces originales.
